# Catch the Turtle 🐢

A simple, reflex-based catching game developed using Python's built-in `turtle` library. The objective is to click on the turtle that appears at random coordinates on the screen within a specified time limit to achieve the highest score.

## 🎮 Features

* **Random Positioning:** The turtle appears randomly across different parts of the screen.
* **Time Limit:** An integrated countdown timer to increase the thrill of the game.
* **Score Tracking:** Your score updates in real-time with every successful click.
* **Simple Interface:** A lightweight, no-installation-required structure built solely with the `turtle` library.

## 🛠️ Technologies Used

* **Python**
* **Turtle** 
* **Random** 
* **Time**
